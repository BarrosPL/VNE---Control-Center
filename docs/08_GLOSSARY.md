# Glossário

## Agent
Entidade lógica que executa uma função via IA/automação.

## Agent Version
Configuração versionada de um agente.

## Capability
Competência conceitual do agente.

## Tool
Operação concreta disponível ao agente.

## Session
Relação contínua entre um agente e uma entidade/contexto.

## Run
Uma execução individual do agente.

## Agent Event
Fato gerado pela operação do agente.

## Entity
Objeto do mundo operacional: lead, contato, processo, conversa etc.

## Binding
Associação entre agente e entidade.

## Human-in-the-loop
Intervenção humana dentro do fluxo do agente.

## Request
Solicitação de ajuda, decisão, validação ou autorização aberta por um agente.

## Takeover
Humano assume o controle operacional de uma entidade.

## Resume
Controle retorna para IA.

## Data Plane
Dados operacionais do negócio.

## Agent Plane
Execução/configuração dos agentes.

## Control Plane
Governança, monitoramento e intervenção.

## Knowledge Item
Informação governada e reutilizável pelos agentes.

## Incident
Falha ou condição anômala que exige acompanhamento.

## Integration Health
Estado operacional de uma integração.

## Audit Log
Registro imutável de ações relevantes.

## Correlation ID
Identificador usado para rastrear uma operação através de sistemas.
